## 데이터와 보안

새 migration `202610170001_newsletter_profiles.sql`은 13번째 테이블인 newsletter_profiles를 추가한다. tenant_id와 user_id의 복합 PK/FK로 멤버십을 연결하고, 모든 CRUD를 본인·소속 팀으로 한정한다. 같은 팀의 owner도 다른 구성원의 개인 설정을 읽거나 바꿀 수 없다. pil_worker는 개인 프로필에 접근할 수 없다. 기존 팀 공통 preferences와 역할 정책은 유지한다.

프로필은 industry, subtopics, scope, country, content_types, name, cadence, updated_at을 저장한다. 앱 Zod와 DB CHECK 양쪽에서 세부 주제의 부모 분야, 국가 선택, 비어 있지 않은 자료 유형을 검사한다. 서버 action은 입력 user_id를 신뢰하지 않고 검증된 로그인 사용자의 ID를 사용한다.

articles에 country_codes(기본 빈 배열)와 content_type(기본 news)을 추가했다. Federal Register 문서는 명시적인 미국 규제 문서 API이므로 US를 기록한다. 언어·도메인만 보고 다른 자료의 국가를 추측하지 않는다. 지역 미확인 자료는 전 세계에만 포함하며 특정 국가 선택에서는 제외한다. 다른 자료의 국가·유형 분류는 허용된 공급자의 메타데이터를 추가로 연결해야 한다. 현재 연구 API는 연결되지 않았으므로 실제 수집 지면에 연구 자료가 없을 수 있다.

실제 지면은 최근 사건 100개의 문서를 검사한다. 제목·출처 제목과 분야/세부 주제 사전의 단어를 비교하고 명시적 지역·유형 필터를 적용한다. LLM 요약이나 사실성 판정이 아니다. 기사 전문을 새로 수집하지 않는다. cadence는 읽기 주기 설정이며 자동 메일 발송 작업을 생성하지 않는다.

공개 미리보기의 콘텐츠는 프로젝트가 작성한 합성 문장이다. 대한민국·미국·일본 예시만 있어 다른 국가 선택 시 빈 상태가 정상일 수 있다. 실제 뉴스·실제 연구 결과·검증된 영향 분석으로 표시하지 않는다. 선택한 주제와 지역은 URL query에 저장되어 수정 버튼이나 새로고침 후에도 유지된다. 프로필이 DB에 저장되는 것은 로그인 후의 /settings 흐름이다.

## 새 버전을 실행하는 방법

기존 서버를 실행한 **일반 PowerShell 창**에서 Ctrl+C로 종료한 뒤 프로젝트 루트에서 실행한다.

```powershell
npm.cmd run build
npm.cmd run preview
```

주소는 `http://127.0.0.1:3100/`이며 관심사 선택은 `/customize`, 뉴스레터는 `/demo`다. 파일 `START_PREVIEW.cmd`를 직접 실행해도 같은 3100번 서버가 시작된다. 터미널 창은 유지한다. 기존 서버를 종료하지 않으면 포트 충돌이 발생하므로 다른 프로세스를 임의 종료하지 않는다.

Supabase를 사용 중이라면 worker와 웹을 새 코드로 실행하기 전에 추가 migration을 적용해야 한다. 기존 자료를 보존하려면 local에서는 `npx supabase migration up`, 연결된 개발 프로젝트에서는 검토 후 `npx supabase db push`를 사용한다. `db reset`은 기존 자료를 지우므로 새 데이터베이스를 초기화할 때만 사용한다.

## 검증 기록

- Next.js 16.4.0 production build / TypeScript: 통과.
- 선택 검증 테스트 6개: URL 왕복, 부모 주제, 국가, 유형, 지역 미확인 제외, 영어 AI 단어 경계, 잘못된 입력 기본값.
- DB/RLS 테스트 8개: 기존 6개와 개인 프로필 사용자 간 격리, CHECK 제약.
- 실제 psycopg 워커 통합 5개와 Python 단위 35개: 새 migration 적용 후 통과.
- HTTP 검증 4개: 공개 합성 표시·보호 경로 차단·로그인 폼·일본/연구/주간 선택 결과를 실제 서버에서 확인. 홈·로그인·관심사 선택·뉴스레터가 HTTP 200 응답을 반환했다.
- 자동 테스트 합계 58개. 실제 브라우저 클릭·모바일 시각 검증은 아래의 연결 제약으로 미완료다.

이 환경에서 Codex 내장 브라우저의 localhost 연결이 시간 초과되어 새 화면의 시각 검증은 아직 완료하지 못했다. 두 레퍼런스 원본은 직접 확인했다. 서버가 Ready를 출력하는 것과 사용자의 브라우저에서 실제 보이는 것은 구분한다.

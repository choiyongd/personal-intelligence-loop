# 2026-10-17 디자인 변경 기준

사용자가 지정한 두 Refero 화면을 브라우저에서 직접 열고 스크린샷 원본을 확인했다. MCP는 NO_SUBSCRIPTION이었으나 공개 상세 화면과 이미지에는 접근할 수 있었다.

| 적용 면 | 기준 | 유지할 요소 | 적용하지 않을 요소 |
|---|---|---|---|
| 사이트·소개·로그인·선택 흐름 | Matter Newsroom & Updates, 281f8078-54b9-4794-be7e-4eb80a395262 | 거의 검은 배경 #0d0d0e, 큰 흰 산세리프 제목, 회색 설명, 여유 있는 섹션 간격, 청보라 CTA, 둥근 제품 프레임 | Matter 로고·카피·앱 이미지·Gmail 연동 주장 |
| 개인 뉴스레터·피드·발행 초안 | Bloomberg Home Page, a86c6668-7903-4bcc-bd43-dc8fef19c6a5 | 흰 지면, 검정 masthead, 큰 굵은 헤드라인, 얇은 선, lead/related/sidebar 다단 편집, 짧은 출처 메타 | Bloomberg 상표·기사·사진·실시간 주가·숫자 복제 |

사이트 외곽을 무조건 밝게 평균내지 않는다. 검은 제품 UI 안에 흰 뉴스레터 지면이 들어간다는 명확한 경계를 유지한다. 청보라는 사이트의 주 행동과 선택 상태에 사용하고, 지면에서는 링크만 파란색으로 표시한다. 기사 카드는 둥근 SaaS 타일보다 divider 기반 편집 구조를 우선한다. 이미지 역할은 실제 자체 뉴스레터 컴포넌트 미리보기와 데이터 유형별 간단한 자체 SVG 도해로 채운다. 외부 기사 이미지는 수집·재배포하지 않는다.

선택 흐름: 관심 분야 → 해당 분야의 세부 주제 → 전 세계/대한민국/특정 국가 → 기사/연구/소식 유형 → 이름과 발행 주기 → 뉴스레터 지면. 로그인 전에는 합성 콘텐츠 미리보기, 로그인 후에는 사용자별 프로필 저장과 실제 수집 자료를 사용한다. 미리보기는 실제 뉴스라고 표시하지 않는다. 저장은 멤버십과 본인 사용자 ID를 검사하고 팀의 공유 선호와 분리한다.

| 결정 | 근거 | 확인 기준 |
|---|---|---|
| 큰 제목과 검정 배경 | Matter 원본 | 로그인·홈·customize에서 유지 |
| 고정된 3단계 progress | 사용자 요구의 의존 순서 | 분야 변경 시 잘못된 세부 주제 초기화 |
| 국가 선택의 명시적 구분 | 사용자 요구 | 전체/한국/특정국가가 URL 및 DB에 기록 |
| 지면과 앱의 명확한 경계 | 두 레퍼런스의 역할 | white paper에 dark ink, 제품 chrome은 dark |
| 자료 유형별 section | 기사·연구·소식 요구 | 빈 유형은 생성하지 않고 coverage 안내 |
| 원문 링크·출처 표시 | 기존 PRD·라이선스 정책 | 실수집 자료에 원문·출처 유지 |

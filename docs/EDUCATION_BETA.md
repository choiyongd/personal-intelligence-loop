# 루프 교육용 베타

기사 읽기에서 시작해 출처 확인, 토론, 근거를 활용한 글쓰기로 이어지는 한국어 수업 도구다.

## 이용 흐름

| 대상 | 시작 | 완료 |
| --- | --- | --- |
| 방문자 | 교육용 페이지에서 같은 기사의 세 난이도를 전환한다 | 출처와 글쓰기 안내를 확인하고 연습 칸에서 써 본다 |
| 교사 | 기관 워크스페이스에서 학급을 만들고 7일 유효한 초대 코드를 발급한다 | 수업을 발행하고 제출 현황을 확인한 뒤 개별 피드백을 남긴다 |
| 학생 | 이메일 계정으로 로그인한 뒤 초대 코드와 교사에게 보일 이름을 입력한다 | 발행된 수업을 읽고 초안을 저장하거나 제출한 뒤 피드백을 확인한다 |

교사는 기사 1~3편과 난이도를 선택한다. 과학·우주, 기술·사회, 환경·정책의 예시 수업은 기사, 읽기 수준, 수업 순서, 글쓰기 주제를 채워 주며 발행 전에 편집할 수 있다. 출처와 숫자는 원래 기사에 연결된다. 예시 페이지의 연습 글은 브라우저 화면에서만 유지된다.

| 수준 | 활동 목표 | 권장 분량 |
| --- | --- | --- |
| 초등 고학년 | 사실과 예를 찾고 내 생활에 연결하기 | 100~250자 |
| 중학생 | 출처가 있는 근거로 주장하고 다른 입장에 답하기 | 250~500자 |
| 고등학생 | 두 출처의 근거를 비교하고 반론과 자료의 한계를 다루기 | 500~900자 |

진행 화면의 수치는 현재 학급에 참여한 학생, 글을 제출한 학생, 교사가 피드백을 남긴 학생을 각각 센다. 학생 초안은 작성자만 볼 수 있다. 글과 피드백은 학급 권한으로 보호하며, 교사가 발행한 수업만 학생에게 표시한다.

## 첫 수업에서 확인할 항목

- 학생이 초대 코드로 들어온 뒤 읽기, 글쓰기, 제출을 스스로 완료하는가
- 학생 글에 기사 속 사실이나 원문 출처를 인용한 근거가 포함되는가
- 교사가 제출 현황을 확인하고 개별 피드백을 남길 수 있는가

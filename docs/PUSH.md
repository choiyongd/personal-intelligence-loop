# 홈 화면 앱(PWA)과 새 소식 알림

## 무엇이 되나요
- **홈 화면 설치**: 안드로이드 크롬·PC 크롬/엣지는 `/my`의 "홈 화면에 설치" 버튼으로, 아이폰은 Safari 공유 › "홈 화면에 추가"로 설치합니다. 설치하면 주소창 없이 앱처럼 열리고(`/my`로 시작), 아이콘은 `public/icons/`에 있습니다.
- **오프라인 화면**: 연결이 끊긴 채 열면 `/offline` 안내가 나옵니다. 그 밖의 페이지는 저장(캐시)하지 않아 항상 최신입니다.
- **새 소식 알림**: `/my`에서 "새 소식 알림 켜기"를 누르면, 매일 아침 새 소식이 써진 뒤 **하루 한 번** "오늘의 새 소식 N편" 알림이 갑니다. 독자가 고른 분야의 소식만 셉니다(없으면 보내지 않음). 누르면 첫 기사가 열립니다. 현재 새 소식이 한국어판에만 있어 알림도 한국어 독자에게만 갑니다.
  - 아이폰·아이패드는 iOS 16.4 이상에서, **홈 화면에 추가한 앱 안에서만** 알림을 켤 수 있습니다(애플 정책).

## 켜는 방법 (운영자가 한 번)
1. **SQL 실행**: Supabase 대시보드 › SQL Editor에서 `supabase/migrations/202611140007_web_push.sql` 내용을 실행합니다. 알림 신청(`push_subscriptions`)과 하루 1회 발송 기록(`push_sends`) 표가 생깁니다. 서버 키로만 읽고 쓸 수 있습니다.
2. **키 만들기**: 아무 컴퓨터에서 `npx web-push generate-vapid-keys`를 한 번 실행하면 Public Key와 Private Key가 나옵니다.
3. **Vercel 환경 변수**: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`(공개 금지), 선택으로 `VAPID_SUBJECT`(예: `mailto:운영자메일`)를 넣고 다시 배포합니다. 키를 나중에 바꾸면 기존 신청이 모두 끊기니 한 번 정하면 그대로 두세요.
4. **확인**: 휴대폰에서 `/my` › "새 소식 알림 켜기" → 허용하면 바로 시험 알림이 옵니다("시험 알림 보내기"는 1분에 한 번).

발송은 기존 `live-news` 워크플로가 기사 쓰기를 마친 뒤 `/api/live?step=notify`를 호출해 합니다. 새 비밀값은 필요 없습니다. 키가 없으면 이 단계는 건너뜁니다. 같은 날 두 번 실행돼도 `push_sends`가 막아 한 번만 보냅니다. 브라우저가 신청을 지운 경우(404/410)나 5번 연속 실패한 신청은 자동으로 정리합니다.

## 구조
- `app/manifest.ts` (설치 정보), `public/sw.js` (알림 표시·클릭, 오프라인 화면), `components/service-worker.tsx` (등록), `components/app-panel.tsx` (`/my`의 설치·알림 카드)
- `app/api/push` (신청 저장/삭제, 같은 사이트에서 온 요청만), `app/api/push/test` (시험 알림), `lib/push.ts` (저장·발송), `lib/push-notice.ts` (알림 문구)
- 비용: 웹 푸시 자체는 무료입니다(브라우저 회사의 푸시 서버 사용).
